# FabriColor

Web comercial + sistema administrativo conectado para FabriColor (Ciudad Bolívar, Venezuela) — tienda especializada en pintura automotriz, agente exclusivo de Goodsif.

## Stack
- Frontend: React + TypeScript + Vite + Tailwind CSS + Zustand (Vercel)
- Backend: NestJS + PostgreSQL, monolito modular (Render)
- DB/Auth: Supabase
